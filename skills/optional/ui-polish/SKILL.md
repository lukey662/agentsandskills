# UI Polish (optional)

Improve hierarchy, spacing, states, and mobile fit without changing product scope. Run after `frontend-design`, not instead of it. If `DESIGN.md` is missing, send Design to `setup` first. Stay surgical inside an existing design system. Still requires desktop and mobile screenshots via `browser-qa`.

Add with `agent-kit add skill ui-polish`.
