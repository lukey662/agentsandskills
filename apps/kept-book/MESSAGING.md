# Messaging — Kept Book

## Discovery (this household product)

- Audience: people who want one kitchen’s recipes in a box, then a book on the counter.
- Pain: recipes live in group chats, heads, and cards. Mixbook is a layout tool. Recipe apps are feeds or meal planners.
- Outcome: a private box, invite-only, a print PDF, a path to a Gelato hardcover.
- Differentiator: Next.js household tool with print-first PDF. Not a public feed. Not AI transcription as the product.
- Proof: none yet. Do not invent user counts.
- Objection: “Isn’t this Mixbook?” Mixbook starts at the page spread. This starts at the card in the box.
- Objection: “Will Gelato just print?” Yes, if you upload the PDF, or later if this app is public with `GELATO_API_KEY`. Today the download is the print path.
- Voice: kitchen-table, short, no heritage-brochure adjectives.
- Conversion: Open this kitchen / Join with a code / Download print PDF.

## Claims we will not make

- AI that “captures grandma’s voice”
- “Bookstore quality” without a real Gelato order in this repo
- Social proof, ratings, or fake recipe counts
